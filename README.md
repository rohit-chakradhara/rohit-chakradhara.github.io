# Rohit AI Portfolio Premium

A futuristic, colorful, light/dark mode personal website for a Data + Product + AI profile.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Notes

- The AI assistant is local/demo only.
- No API key is required.
- Theme is handled with next-themes.
- The site avoids browser-extension hydration issues by keeping the UI deterministic.
